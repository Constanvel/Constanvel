# Constantine Rainer Simanjuntak

[English](README.md) | **Bahasa Indonesia**

Pelajar rekayasa perangkat lunak di **SMK Telkom Purwokerto, Indonesia**, berfokus pada pengembangan front-end dan menekuni jalur **AI engineering**.

Saya membangun pengalaman front-end secara menyeluruh: tata letak halaman, komponen yang dapat digunakan ulang, antarmuka aplikasi, dan game edukasi berbasis browser.

### Proyek pilihan

#### Aplikasi web

- **[SAGARA](https://github.com/Constanvel/Sunatan)** — Website informasi layanan dengan alur pendaftaran melalui WhatsApp, menggunakan **Next.js, React, dan TypeScript**. **Peran saya: Front-end Developer — membangun seluruh front end**, termasuk semua halaman, komponen yang dapat digunakan ulang, tata letak responsif, dan antarmuka pendaftaran. Permintaan tetap memerlukan konfirmasi admin. [Kunjungi website](https://sagara-vert.vercel.app).
- **[Lensa](https://github.com/Constanvel/Lensa)** — Platform esai analitis tentang karakter fiksi, dengan jenis klaim, sitasi, dan tanggapan terstruktur. Menggunakan **Next.js, TypeScript, Tailwind CSS, dan Supabase**. **Peran saya: Front-end Developer — membangun seluruh front end**, termasuk semua halaman, pustaka komponen, antarmuka membaca dan menulis esai, serta layar autentikasi.
- **[Website SMK Telkom Purwokerto](https://github.com/Constanvel/smk-telkom-purwokerto)** — Website sekolah yang dikembangkan sebagai proyek tim. **Peran saya: Front-end Developer — membangun seluruh front end**, termasuk semua halaman website dan antarmuka dashboard admin.

#### Alat AI

- **[AI Text Summarizer](https://github.com/Constanvel/AI-Text-Summarizer)** — Alat **JavaScript** untuk penggunaan pribadi yang merangkum teks melalui **Groq API**, dengan pilihan panjang ringkasan, penghitung kata, fitur salin, dan penanganan error.

#### Game edukasi

- **[Gundul Warrior](https://github.com/Constanvel/Projek-Matematika)** — Game platformer **JavaScript dan Canvas 2D** untuk mempelajari fungsi dan komposisi. **Peran saya: Front-end Developer — membangun seluruh pengalaman di sisi browser**, termasuk rendering game, menu, antarmuka soal, kontrol keyboard dan sentuh, serta penyimpanan progres lokal. Memuat 12 soal dalam tiga wilayah, checkpoint, unit test, dan pengujian browser dengan Playwright.

Eksperimen lainnya: **[BARA 1946](https://github.com/Constanvel/BARA-1946)**, prototipe game sejarah Roblox bergaya retro dengan eksplorasi, dialog, dan pertarungan arcade; serta **[Bandung 1946 — Garis Pertahanan](https://github.com/Constanvel/Tugas-Sejarah)**, fondasi awal **Godot/GDScript** dengan pergerakan, kamera, collision, dan menu.
